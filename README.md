
# 🚀 Career Pilot AI

## 📌 Problem

Many students are confused about choosing the right career path based on their skills, interests, and goals.

## 💡 Solution

Career Pilot AI is an intelligent system that analyzes user input and suggests the most suitable career roles, explains why they fit, and helps users take the next step by generating a professional email to contact recruiters.

## 🧠 Features

* AI-based career role suggestions
* Personalized recommendations based on user input
* Automatic professional email generation
* Workflow automation using n8n
* User-friendly interface

## 🛠️ Tech Stack

* Frontend: Lovable (React + Vite)
* Automation: n8n
* Styling: Tailwind CSS

## ⚙️ How it works

1. User enters their skills and interests
2. AI analyzes the input
3. Suggests suitable career roles
4. Explains why the role fits
5. Generates a professional email
6. Sends email using automation workflow
